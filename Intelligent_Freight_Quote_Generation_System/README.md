# 🚛 Cargo Genius

> AI-Powered Intelligent Freight Quote Generation & Management System

Cargo Genius is a modern web application that automates freight quote generation and shipment management. It helps logistics companies, freight brokers, and businesses calculate shipping costs instantly using distance, cargo details, and intelligent pricing rules while providing an easy-to-use dashboard for managing quotes.

---

## 📌 Problem Statement

Freight quotations are often created manually, making the process slow, inconsistent, and prone to errors. Businesses need a faster and smarter way to generate accurate shipping quotes while efficiently managing customer shipments.

Cargo Genius solves this by automating quote generation and freight management through an intelligent pricing engine.

---

## 🚀 System Workflow

1. Customer registers and logs in.
2. Customer enters shipment details.
3. System calculates travel distance.
4. Intelligent pricing engine estimates freight cost.
5. Quote is generated instantly with complete cost breakdown.
6. Users can view quote history and dashboard.
7. Admin manages pricing rules, fuel surcharge, and system settings.
